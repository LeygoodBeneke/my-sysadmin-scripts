Скрипт раз в N секунд снимает free -h, df -h, uptime и дописывает в monitor.log блок из этих трёх выводов с временной меткой в начале, например: --- 2026-08-15 14:03:00 ---, дальше сами выводы free -h/df -h/uptime построчно. N — захардкоженная константа в скрипте, интерактивный ввод не нужен.

Оператор >> сам создаёт файл, если его нет, а если есть — дописывает в конец.
